## 1. Creative Concept & Visual Architecture

- **Visual Direction**: Premium dark futuristic theme (`#050505` deep void), electric purple (`#a855f7`) and neon cyan (`#00f0ff`) accents, metallic PBR chrome materials, frosted glass cards, and cyber-grid HUD elements.
- **Hero Experience**: Real-time interactive 3D floating kinetic structure reacting to mouse motion via damped spherical interpolation, illuminated by neon point lights and enveloped in 850+ ambient cosmic space particles.
- **Section 2 — The Agency**: Brand story, 4 core architectural pillars, and live benchmark telemetry metrics.
- **Section 3 — Capabilities**: 6 interactive service cards with custom glowing icon badges, deliverable matrices, and hover states:
  1. *3D Web Experiences*
  2. *Creative Advertising*
  3. *Website Development*
  4. *UI/UX Design Systems*
  5. *Digital Branding*
  6. *AI-Powered Solutions*
- **Section 4 — Selected Work**: Interactive portfolio gallery with category filtering (`All`, `3D Web`, `AI Platforms`, `Creative Tech`, `Brand Systems`), labeled concept prototypes, and a full-screen specification inspection modal.
- **Section 5 — Interactive 3D Lab**: Live WebGL sandbox allowing visitors to switch 3D geometries (Knot, Icosahedron, Octahedron, Torus), toggle PBR shaders (Iridescent, Chrome, Wireframe, Hologram), select lighting aurors (Cyberpunk, Violet, Cyan, Gold), and freely orbit with touch or mouse.
- **Section 6 — The SATULLAEV Standard**: Real-time client-side performance monitor (live FPS counter, display DPR, GPU renderer string) and high-tech feature matrix comparing SATULLAEV standards against ordinary agencies.
- **Section 7 — Futuristic Contact Experience**: Glassmorphism contact form with field-level validation, multi-select service options, budget ranges, direct mailto fallback, and turnkey integration for external API endpoints.
- **Section 8 — Minimal Modern Footer**: `SATULLAEV © 2026`, SSL status beacon, navigation directory, social links, and smooth back-to-top button.
- **Micro-Interactions**: Web Audio API sci-fi synthesizer providing subtle chirps and tactile clicks (with a quick mute toggle in the navigation bar) and a smooth trailing custom cursor.

## 6. AWS EC2 (Ubuntu Linux) Deployment Guide

Your production environment:
- **Server**: AWS EC2 instance running Ubuntu Linux
- **Web Server**: Nginx
- **Domain**: `https://satullaev.uz`
- **Target Document Root**: `/var/www/html`

### Step 1: Transfer Code or Build on EC2

#### Option A: Build Locally and Upload `dist/` to EC2
On your local machine, run:
```bash
npm run build
rsync -avz -e "ssh -i /path/to/your-key.pem" ./dist/ ubuntu@your-ec2-ip:~/satullaev-dist/
```

#### Option B: Clone and Build Directly on EC2
SSH into your AWS EC2 instance:
```bash
ssh -i /path/to/your-key.pem ubuntu@your-ec2-ip
```

Install Node.js LTS (if not already installed):
```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs nginx rsync
```

Clone your repository and build:
```bash
cd ~
git clone <your-repository-url> satullaev-agency
cd satullaev-agency
npm install
npm run build
```

---

### Step 2: Safe Deployment to `/var/www/html`

To prevent overwriting existing server files without a backup, use the included `deploy.sh` script:

```bash
chmod +x deploy.sh
./deploy.sh
```

Or execute the steps manually:

```bash
# 1. Create a timestamped backup of the current /var/www/html
sudo mkdir -p /var/www/backups
if [ -d "/var/www/html" ] && [ "$(ls -A /var/www/html)" ]; then
  sudo cp -r /var/www/html /var/www/backups/html_backup_$(date +%Y%m%d_%H%M%S)
  echo "Backup successfully created in /var/www/backups"
fi

# 2. Synchronize compiled dist files into /var/www/html
sudo mkdir -p /var/www/html
sudo rsync -av --delete ./dist/ /var/www/html/

# 3. Set proper ownership and permissions for Nginx
sudo chown -R www-data:www-data /var/www/html
sudo find /var/www/html -type d -exec chmod 755 {} +
sudo find /var/www/html -type f -exec chmod 644 {} +
```

---

### Step 3: Configure Nginx for React SPA Routing & SSL

1. Copy the provided configuration file:
```bash
sudo cp nginx/satullaev.uz.conf /etc/nginx/sites-available/satullaev.uz
```

2. Enable the site by creating a symlink in `sites-enabled`:
```bash
sudo ln -sf /etc/nginx/sites-available/satullaev.uz /etc/nginx/sites-enabled/
```

3. Obtain an SSL certificate using Let's Encrypt Certbot (if not already acquired):
```bash
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d satullaev.uz -d www.satullaev.uz
```

4. Test Nginx syntax and reload:
```bash
sudo nginx -t
sudo systemctl reload nginx
```

---

### Step 4: Verification Commands

Verify that the site is properly served with HTTPS and correct HTTP headers:

```bash
# 1. Verify Nginx status
sudo systemctl status nginx

# 2. Check HTTP to HTTPS redirect
curl -I http://satullaev.uz

# 3. Check HTTPS response (Should return HTTP/2 200 OK)
curl -I https://satullaev.uz

# 4. Check that SPA routing works for deep paths
curl -I https://satullaev.uz/services
```

## 7. Connecting a Backend for the Contact Form

The contact form in `src/components/Contact.tsx` is built with real validation and works immediately:
- **Default Mode**: If no API URL is provided, clicking "Submit" formats the brief and triggers a pre-filled client dispatch to `contact@satullaev.uz`.
- **API Endpoint Mode**: To route submissions through a webhook or backend server (e.g., Formspree, Resend, SendGrid, or your own Node.js/Python microservice on EC2):

1. Create a `.env` file in the project root:
```env
VITE_CONTACT_API_URL="https://formspree.io/f/your_form_id"
```
*(Or your own server endpoint: `https://satullaev.uz/api/contact`)*

2. Rebuild the application:
```bash
npm run build
./deploy.sh
```

When `VITE_CONTACT_API_URL` is set, the form sends a `POST` request with JSON:
```json
{
  "name": "Aziz Satullaev",
  "email": "aziz@example.com",
  "service": "3D Web Experiences",
  "budget": "$15,000 - $35,000",
  "message": "We require a bespoke 3D brand portal..."
}
```
